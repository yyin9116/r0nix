# r0nix

r0nix 是一个面向科研阅读的 PDF + 网页一体化工具，支持阅读、截图导出（SVG/PNG/JPG）、资料库管理与阅读历史追踪。

## 主要功能

- PDF 阅读：缩放、翻页、缩略图导航、继续阅读
- 网页与 PDF 联动：在应用内打开链接与 PDF
- 图片导出：支持 SVG / PNG / JPG
- 资料库：收藏、分组、导出文献列表
- 数据备份：导出/导入设置与使用数据（历史、收藏、资料库等）

## 安装与启动

### 1) 下载安装包

前往 GitHub Releases 下载对应系统安装包：

- Windows: `.exe` (NSIS) 或 `.msi`
- macOS: `.dmg`

安装后直接启动 `r0nix`。

### 2) 首次使用建议

- 在设置中配置默认导出格式与保存路径
- 根据需要设置“链接在应用内打开”
- 需要网络代理时，在设置里填写代理地址

## 使用说明

### 打开文献

- 侧边栏点击“打开 PDF”
- 或使用顶部菜单 “文件 -> 打开 PDF”

### 网页探索

- 新建网页标签页后输入网址
- 网页中的 PDF 链接可直接在应用内打开（可在设置中切换行为）

### 导出图片

- 在 PDF 中框选后导出
- 支持 SVG、PNG、JPG

### 资料库与历史

- 在资料库中管理文献、收藏、分组
- 可导出文献列表（CSV / Markdown / JSON）

### 备份与恢复

- 设置页 -> 数据备份：导出全部设置与使用数据
- 设置页 -> 数据备份：导入并恢复数据

## 常见问题


### 网页无法打开部分站点

部分站点可能限制嵌入或跨域策略，可切换到外部浏览器打开。
